# Гра "Поле чудес" (C++)

Консольна гра "Поле чудес" для дисципліни "Програмування з використанням мови C++".

## Опис

- Випадково обирається питання із зашифрованим словом.
- Гравець обирає: назвати літеру, назвати ціле слово чи скористатись підказкою.
- За правильну літеру відкривається її позиція у слові, за помилку — втрачається спроба (усього 6 спроб).
- Кожна використана підказка додає +2 секунди до підсумкового часу.
- Наприкінці гри виводиться загальний час розгадування з урахуванням підказок.

## Особливості реалізації

- Кольорове оформлення консолі (`SetConsoleTextAttribute`).
- Ефект друку тексту по буквах із затримкою (`Sleep`/`this_thread::sleep_for`).
- Підтримка кирилиці через кодову сторінку UTF-8 (`chcp 65001`).
- Заміри часу через `<chrono>`.

## Збірка та запуск (Windows, MinGW / MSVC)

```bash
g++ -std=c++17 -O2 main.cpp -o game.exe
game.exe
```

Або через Visual Studio: створіть новий консольний проєкт і додайте `main.cpp`.
